# Style kit: стилистика интерфейса

Один файл для переноса в новый проект. Объединяет принципы (style.md) и значения страницы (page.md). Положить в `specs/`, сослаться из `CLAUDE.md`. Дровер «О запросе» и дровер чата описаны отдельно (drawer-info.md, drawer-chat.md), здесь их нет.

Суть: сильные скругления, плавающие карточки, мягкие тени, плотный интерфейс, только Roboto. Все значения сопоставляются с токенами Kernel (`--palette-*`); инлайном только то, чего в Kernel нет.

## Цвета (Figma → Kernel)
- `rgb(240,240,240)` → `grey-2`: фон страницы, hairline, разделители, серые кнопки.
- `rgb(246,246,246)` → `grey-1`: плашки, секции. `rgb(250,250,250)` → `grey-0`: нейтральные кнопки и чипы.
- `rgb(255,255,255)` → `a1`: поверхности (рейл, карточки, списки).
- `rgb(38,38,38)` → `grey-7`: основной текст, тёмные плашки. `rgb(89,89,89)` → `grey-6`: вторичный текст, иконки. `rgb(140,140,140)` → `grey-5`: подписи. `grey-4`: неактивное.
- `rgb(252,108,64)` → `cryola-5`: акцент (кнопки, бейджи, активное, иконки предупреждений). `rgb(246,61,4)` → `cryola-6`: обводки иконок, активный пункт меню.
- `rgb(148,96,230)` → `amethyst-5`: AI. `blue-5`: ссылки. Статусы: `dustred-*` ошибка (фон `dustred-0`, текст `dustred-6`), `green-*` успех.
- Нет в Kernel (инлайн, при использовании уточнять): `rgb(86,216,88)`, `rgb(41,218,130)` зелёные индикаторы; `rgb(124,124,124)` трек прогресса; `rgb(247,248,250)` фон чата; `rgb(50,43,44)` логотип; `rgb(45,44,48)`; `rgb(249,237,227)`/`rgb(251,246,242)`/`rgb(246,222,197)` градиент баннера «Внимание!»; тени `rgba(234,36,36,…)` у «Tarif».

## Типографика
- Только Roboto. Плотная шкала: 10/13 Regular (подписи, uppercase заголовки блоков), 11 Medium, 12/20 (основной текст, Bold для значений и заголовков баннеров), 12/17 (лейблы фильтров), 14 (названия, кнопки), 16 (заголовки блоков), 19–24 (крупные заголовки), 30/38 Black (крупные числа статистики).
- Веса: 500 акцентные подписи и кнопки, 700 заголовки и названия, 400 точечно.
- Русские подписи блоков в верхнем регистре (`ПРИСЛАННЫЕ СЧЕТА`): 10/13, `grey-5`.
- Цвет текста: `grey-7/6/5`, на тёмном — `a1`.

## Скругления
- 16 внешние карточки (рейл, рабочая область, секции) · 14 дроверы, модалки, Tarif · 12 вложенные блоки, плашки, шапка-крошка, пункты рейла · 10 баннеры, кнопка-иконка, составные плашки · 8 мелкие элементы (кнопки, строки, файлы, инпуты, карточки списков) · 6 микроэлементы · 20 чипы и прогресс (pill) · 50% аватары, точки, круглые кнопки.
- Прямых углов у поверхностей нет.
- Вложенность концентрическая: внешний радиус = внутренний + отступ (16 → 12 при padding 4–6; 14 → 8–12 при padding 8). Внутренний радиус не больше внешнего.
- Составные плашки скругляю только по внешним углам (`10 0 0 10` + `0 10 10 0`), зазор 1.

## Плавающие карточки и слои
- Страница — подложка `grey-2`. На ней рейл слева (80px, inline-меню 64px) и рабочая область справа: две белые (`a1`) карточки radius 16, отступ от края и между ними 6. Внутри рабочей области padding 6, зазор 6.
- Нижний слой — контентная карточка. Заголовок страницы (высота 45) лежит прямо на ней, без своей подложки.
- Рабочая область под заголовком (список, таблица) — отдельная карточка слоем выше: radius 12, `a1`, `inset 0 0 0 1px grey-2, 0 0 24px rgba(0,0,0,.05)`, padding 8, занимает остаток высоты.
- Карточка не прилипает к краям: рейл, шапка, поле ввода, Right Bar, дровер — отдельные плавающие блоки со своим радиусом и отступом.
- Секция = подложка `grey-1` (radius 16, padding 4) + белый внутренний блок (radius 12) с hairline: карточка в карточке.
- Подложки: `grey-2` страница, `grey-1` секции и плашки, `grey-0` нейтральные кнопки, `rgb(247,248,250)` чат.
- Дровер и модалка — высшая плоскость: отступ 8 от краёв (дровер), затемнение `rgba(38,38,38,.7)` (= `grey-7` @ 70%).
- Шапка и поле ввода в чате парят поверх колонки сообщений.
- Активная страница в заголовке — вертикальная метка 4×38 (`cryola-5`, радиус справа 6).

## Границы и разделители
- `border` не использую. Граница — hairline `box-shadow: inset 0 0 0 1px grey-2`.
- Разделители внутри блоков: `inset 0 -1px 0 grey-2` (под строкой), `inset 0 1px 0 grey-2` / `0 -1px 0 grey-2` (над нижней панелью).
- Тень и hairline объединяю в один `box-shadow`.

## Тени
Мягкие, широкие, нейтральные чёрные с малой прозрачностью; глубину создают вместе с hairline, а не вместо него. Шкала по высоте плоскости:
- пузырь сообщения `0 0 4px rgba(0,0,0,.05), 0 1px 0 rgba(0,0,0,.04)`
- карточка статистики `0 2px 6px rgba(0,0,0,.08)`
- панель на странице `inset 0 0 0 1px grey-2, 0 0 24px rgba(0,0,0,.05)`
- шапка, поле ввода, Right Bar `0 8px 25px rgba(0,0,0,.05)`
- подсказки и меню `0 0 24px rgba(0,0,0,.12)` или `var(--shadow-dropdown)`
- поповеры `0 3px 6px -4px rgba(0,0,0,.12), 0 6px 16px 0 rgba(0,0,0,.08), 0 9px 28px 8px rgba(0,0,0,.05)`
- дровер `0 0 64px rgba(0,0,0,.25)`
- исключение: акцентный блок «Tarif», многослойная тень цвета акцента (6 слоёв).

## Размеры и отступы
- Зазоры: 4 / 6 / 8 / 10 / 16 / 24. Внутренние отступы блоков: 4, 6, 8, реже 11–12.
- Высоты контролов: 28 (small-кнопки), 36, 40 (панели), 45 (заголовок страницы), 56 (пункт меню), 72 (элемент списка).
- Плотный интерфейс: текст 10–14px, компактные контролы 28–40px.

## Компоненты
- Сначала ищу в Kernel: Button (28/36/44, Filled/Outline, Cryola/Blue/Amethyst), Input, Checkbox, Avatar и др. Названия в Figma могут отличаться: сначала сопоставляю с токенами и компонентами Kernel.
- Нет в Kernel: Filter item, List Items, Mail_menu_items, Region, Statistic, Switch, Sort, badge, banner/AI-assistant. Собираю по этому стилю, детали уточняю.
- Артефакты рендера Figma (иконки, наложенные на текст кнопок) в вёрстку не переношу.

## Движение
- Дроверы и модалки: появление 0,3 с, затемнение 0,25 с, дроверы не накладываются друг на друга.
- Страница: fade + сдвиг 8px за 0,28 с; прогресс `width .4s`; быстрые сообщения `opacity .2s`.
- Hover: смена фона на `grey-1`/`grey-0` или цвета текста, без теней.
